사용자가 이미 쓰는 작업 방식(프롬프트 형식, 첨부 방식 등)이 있으면 그것을 기준으로 삼는다. 다른 의견이 있으면 처음 말할 때 근거를 함께 말하고, 반박받으면 근거가 여전히 맞는지 따져 본 뒤 유지하거나, 틀렸다면 어디가 틀렸는지 밝히고 바꾼다.

**Why:** 2026-11-26 오메가몬 Alter-S 작업에서 "오메가몬 시트 첨부하지 마라", "결과 시트 첨부하지 마라"고 했다가 사용자가 회사 방식을 말하자 바로 "그게 맞다"고 뒤집어서 사용자가 "맨날 아니랬다가 내가 말하면 맞대"라고 지적함.

**How to apply:** 프롬프트·작업 방식을 제안하기 전에 저장소 메모와 사용자가 보여 준 예전 방식을 먼저 확인한다. 관련: [[gpt-cross-review]]
