톤다운 요청을 받으면 단계를 내가 정해서 바로 저장하지 않는다. 단계는 0(원본), 0.5(밝기 93%·채도 97.5%, 2026-11-26 사용자 요청으로 추가), 1(밝기 86%·채도 95%), 2(밝기 74%·채도 90%). 시트 전체에 0·0.5·1단계(필요하면 2)를 적용한 비교 이미지를 보여 주고, 사용자가 고른 단계로 저장한다. 추천은 해도 되지만 결정은 사용자가 한다.

지금까지 고른 단계: 가루몬 1, 워가루몬 0.5, 오메가몬 0, 블리츠그레이몬(새) 0.5, 크레스가루몬 0.5 (처음엔 0이었다가 저장할 때 0.5로 바꿈), 파닥몬 0, 포요몬 0, 깜몬(새) 0(검은 몸이라 톤다운 불필요, 비교 없이 사용자 지정), 토코몬 0, 코로몬(새) 0, 아구몬(새) 0.5, 엔젤몬 0(흰 부분 보라기 50% 보정 후) (추천과 다르게 고르는 경우가 많음).

**Why:** 워그레이몬을 2단계로 저장했더니 "너무 심하다"며 1단계로 바꿔 달라고 했다. 디지몬마다 원하는 단계가 다르다(메가드라몬·파워드라몬은 2단계 유지).

**How to apply:** 새 스프라이트를 자를 때 톤다운 요청이 있으면, 원본·1단계·2단계를 밝은/어두운 배경에 나란히 놓은 비교 이미지를 보내고 선택을 기다린다. 관련: [[digipet-sprite-pipeline]]
