# DigiPet 진화 아틀라스

`dist/index.html` 또는 `../진화표_작업/진화표.html`을 더블클릭해서 엽니다. 인터넷 연결이나 서버 없이 동작하며, 그림까지 HTML 한 파일에 포함되어 있습니다.

- 주변 경로: 디지몬을 선택하면 바로 이전·다음 진화를 표시합니다.
- 전체 진화표: 104종과 188개 연결을 빈 영역을 마우스로 드래그하거나 가로·세로 스크롤과 확대/축소로 탐색합니다.
- 도감: 이름 검색, 단계, 그림 구현 완료/미구현 상태로 필터링합니다.
- 조그레스: 4가지 조합과 재료·결과의 그림 준비 상태를 표시합니다.
- 구현 완료는 그림 PNG가 준비된 상태를 뜻합니다.

## 자료 갱신

작업표나 그림을 추가한 뒤 이 폴더에서 `python build.py`를 실행합니다. `../진화표_작업/진화트리_설명.md`의 2~6장과 `그림/이름.png`를 읽어 HTML 두 곳을 갱신합니다. 단계별 종 수, 104종, 연결 대상, 진화 방향, 조그레스 4쌍을 검증합니다. 작업표의 전체 종 수가 변경되면 검증 기준도 함께 변경해야 합니다.

작업 폴더가 없는 환경에서는 함께 저장한 `data.json` 스냅샷으로 HTML을 재생성합니다. 데이터와 그림은 생성 시점 기준이며 자동 동기화하지 않습니다.

수치 진화 조건은 작업표에 정의되지 않아 추가하지 않았습니다. 게임 규칙과 세이브는 수정하지 않습니다.
