# DigiPet 진화 아틀라스

`dist/index.html` 또는 `../진화표_작업/진화표.html`을 더블클릭해서 엽니다. 그림까지 HTML 한 파일에 포함되어 있어 오프라인에서도 저장된 자료로 동작합니다. 인터넷에 연결되면 GitHub의 최신 그림을 자동 확인합니다.

- 주변 경로: 디지몬을 선택하면 바로 이전·다음 진화를 표시합니다.
- 전체 진화표: 104종과 188개 연결을 빈 영역을 마우스로 드래그하거나 가로·세로 스크롤과 확대/축소로 탐색합니다.
- 도감: 이름 검색, 단계, 그림 구현 완료/미구현 상태로 필터링합니다.
- 조그레스: 4가지 조합과 재료·결과의 그림 준비 상태를 표시합니다.
- 구현 완료는 그림 PNG가 준비된 상태를 뜻합니다.

## 자료 갱신

### GitHub 그림 자동 동기화

연동 저장소는 `peo906/ksy_digimon`, 브랜치는 `main`, 그림 폴더는 `진화표_작업/그림/`입니다.

1. 해당 폴더에 진화표의 이름과 일치하는 `디지몬이름.png`를 추가하고 `main`에 커밋·푸시합니다. 예: `에렉몬.png`, `메탈그레이몬(청).png`.
2. 사이트를 열 때 자동 확인하며, 열어 둔 화면에서는 5분마다 확인합니다. `지금 동기화`로 즉시 확인할 수도 있습니다.
3. 추가·교체·삭제에 맞춰 그림, 구현 상태, 도감 필터, 단계별 집계를 함께 갱신합니다. 버전이 고정된 이미지 주소를 사용해 교체 전 그림이 남지 않도록 합니다.

GitHub 저장소는 현재 공개이므로 방문자 토큰 없이 읽습니다. 공개 GitHub API에 요청 제한이 걸리거나 인터넷·그림 로딩이 실패하면 기존 자료를 유지하고 화면에 실패 상태를 표시합니다. 저장소를 비공개로 바꾸면 이 방식으로 동기화할 수 없습니다. 사이트를 닫아 둔 동안 서버가 별도 갱신되는 구조는 아니며, 다음 접속 때 최신 커밋을 읽습니다.

`resource/디지몬/`에만 올린 파일, 원본 ZIP, 진화표에 없는 이름의 그림은 자동 등록되지 않습니다. 기본 자세 PNG를 위 그림 폴더에도 이름에 맞춰 올려 주세요. 새 디지몬 자체나 진화 경로를 추가할 때는 작업표를 수정하고 아래 재생성을 진행해야 합니다.

### 진화표 구조·오프라인 자료 재생성

작업표나 그림을 추가한 뒤 이 폴더에서 `python build.py`를 실행합니다. `../진화표_작업/진화트리_설명.md`의 2~6장과 `그림/이름.png`를 읽어 HTML 두 곳을 갱신합니다. 단계별 종 수, 104종, 연결 대상, 진화 방향, 조그레스 4쌍을 검증합니다. 작업표의 전체 종 수가 변경되면 검증 기준도 함께 변경해야 합니다.

작업 폴더가 없는 환경에서는 함께 저장한 `data.json` 스냅샷으로 HTML을 재생성합니다. HTML에는 `github-sync.js`도 함께 포함되므로 별도 서버 설치가 필요 없습니다. 진화 경로 자체는 생성 시점의 작업표를 따릅니다.

검증: `node test-github-sync.cjs`, `node test-drag.cjs`, `python build.py`.

수치 진화 조건은 작업표에 정의되지 않아 추가하지 않았습니다. 게임 규칙과 세이브는 수정하지 않습니다.
