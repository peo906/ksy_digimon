# 02번(걷기) 프레임 – 규칙과 참고 자료

회사·집 어느 PC에서 열어도 같은 기준으로 02번을 만들고 고칠 수 있게 정리한 폴더다. (2026-11-27)
진행 체크와 디지몬별 요청문은 `원본그림/02_걷기_수정목록.md`, 01번 원본은 `원본그림/02_수정용/`.

## 게임이 02번을 쓰는 방식

- `pet.pyw`의 걷기는 **01번(기본)과 02번(걷기)을 6틱(0.3초)마다 번갈아** 보여 준다. 몸 전체를 좌우로 옮기는 것은 게임이 한다.
- 그래서 02번은 "걷는 한 장면"이 아니라 **01번과 번갈아 봤을 때 리듬이 생기는 짝**이어야 한다.
- 02번에서 발을 들거나 한 발을 크게 내딛으면, 2프레임으로는 걷는 것도 서 있는 것도 아닌 어색한 모습이 된다(새 그림 대부분이 이 문제, 2026-11-27 사용자 지적).

## GPT로 02번만 다시 그릴 때 배운 것

| 파일 | 요청 | 결과 |
|---|---|---|

| (이미지 없음) | 무릎 굽혀 3~5px 내림 | 쪼그려 앉음 → 실패 |
| `04_시험_레이디데블몬_팔하나_성공.gif` | 앞쪽 팔 하나만 앞으로 흔들기 | **채택** |
| `04_시험_레이디데블몬_반대팔_실패.gif` | 반대 팔을 뒤로 | 팔이 등 뒤로 꺾임 → 실패 |
| `04_시험_묘티스몬_고개내뺌_실패.gif` | 머리를 앞으로 키의 2% | 고개를 앞으로 내빼는 모습 → 실패 |

정리:
- 다리·무릎·엉덩이 높이·발은 "01번과 똑같다"고 강하게 고정한다. "굽혀라", "내려라"는 쓰지 않는다.
- 머리는 앞으로 빼지 않는다(필요하면 살짝 내리기만).
- 공통 문구 하나로는 안 된다. **디지몬마다 움직일 곳을 따로 정한다.** 망토·날개·꼬리·큰 팔이나 무기처럼 면적이 크고 그 디지몬다운 부위를 주인공으로.
  예: 묘티스몬 = 망토 자락 펄럭 + 상체 1~2px 기울임 + 늘어뜨린 손 손가락 오므림, 머리·가슴 손·다리 고정.
- 첨부는 그 디지몬의 01번 한 장(+ 필요하면 `원본그림/02_수정용/00_걷기_참고_파워드라몬.png`).

## 02번 한 장 교체 방법

1. 새 02 누끼 PNG를 받으면 01번과 **같은 배율**로 맞춘다(12장 중 최대 키 기준 배율, 발바닥을 96칸 맨 아래, 반투명 128 기준 제거, wide면 가로 확장).
2. 톤다운한 디지몬이면 같은 톤 적용(`_claude_규칙/memory/tone-down-choice.md`).
3. 기존 02는 `원본그림/<폴더>/02_이전.png`로 백업하고 `resource/디지몬/<폴더>/<폴더>_02.png`만 바꾼다.
4. 저장 전 01과 번갈아 보이는 0.3초 GIF로 확인.
5. `python 원본그림/_도구/evo_chart.py` → `cd evolution-atlas && python build.py`로 진화표·사이트 갱신.

## 2026-11-27 15종 작업으로 정해진 방식 (위 내용보다 우선)

15종(묘티스몬 … 베놈묘티스몬) 02를 이 방식으로 바꿨다. 디지몬별 요청문은 `원본그림/02_수정용/번호_이름_요청문.txt`.

**움직임 정하기**
- 디지몬마다 "주로 움직이는 곳 / 같이 조금 / 고정"을 따로 정한다(제안표는 목록 파일 끝). 사용자가 보고 고친다.
- 잘 된 것: 망토·천 펄럭(묘티스몬, 레이디데블몬), 날개 내림(엔젤몬, 메가드라몬, 마왕몬, 베놈묘티스몬, 시라몬 지느러미), 네발 = 머리 바로 아래로 끄덕 + 갈기·등 날개 눕히기 + 꼬리(가루몬, 메탈가루몬), 뱀형 = 입 크게 벌리기 + 꼬리 끝 말기(메탈시드라몬), 앞팔 하나 들기 + 머리 살짝 내림(워그레이몬, 블랙워그레이몬), 뒤쪽 팔 가드 올리기(워가루몬).
- 안 된 것: 가는 팔 앞으로 흔들기(레이디데블몬, 어색), 큰 대포를 벌리기(블리츠그레이몬, 가려져 있던 골반이 드러나 "골반이 움직이는" 것처럼 보임 → 포구만 기울이기로 해결), 아래턱만 내리기(메탈시드라몬, 턱이 늘어나고 혀가 사라짐).
- 양은 "살짝" 대신 구체적으로: 머리 = 머리 높이의 1/8만큼 바로 아래로(앞으로 내밀지 않음), 갈기·머리카락 = 한 가닥 굵기, 꼬리 = 꼬리 굵기, 날개 = 끝이 "뿔 끝보다 낮고 어깨보다 조금 높은 곳"처럼 몸 기준 위치. "살짝"만 쓰면 01과 거의 같은 그림이 나온다(메탈시드라몬 1차: 테두리 1px만 다름).

**첨부 2 고르기 – 몸 구조가 비슷한 그림의 01/02**
- 날개·날개형: 에어드라몬 옛 도트(`00_걷기_참고_에어드라몬.png`), 날개 달린 사람형은 새 마왕몬(`00_걷기_참고_마왕몬.png`).
- 뱀형: 시드라몬 옛 도트(`00_걷기_참고_시드라몬.png`). 두발 공룡형: 그레이몬 옛 도트(`00_걷기_참고_그레이몬.png`).
- 같은 몸이면 끝난 새 그림을 그대로: 블랙워그레이몬 ← 새 워그레이몬(`00_걷기_참고_워그레이몬.png`).
- 사람형 체형 + 다른 움직임이면 둘 다 첨부(워그레이몬: 첨부 2 = 마왕몬 체형·다리 고정, 첨부 3 = 그레이몬 움직임). 참고 그림의 움직임을 따라 하면 안 되는 부분은 "날개 움직임은 따라 하지 않는다, 등 방패 고정"처럼 막는다.
- 마땅한 게 없으면 파워드라몬(양 기준만, "이번엔 발 모두 고정"을 덧붙임). 참고 이미지는 `python 원본그림/_도구/02_교체/ref.py <폴더> <01파일> <02파일> <이름>`으로 만든다.

**요청문 [형식]에 항상 넣는 것**
- "첨부 1과 같은 도트 화풍(픽셀이 보이는 게임 스프라이트)… 매끈한 일러스트 선이나 굵은 만화 선으로 바꾸지 않는다" (크레스가루몬이 매끈한 일러스트로 나온 뒤 추가).
- "배경은 투명(알파 채널이 있는 PNG 파일로 출력). 회색·흰색 체크무늬 배경을 그려 넣지 않는다…" → GPT가 누끼까지 해 준다(크레스가루몬 이후 전부 진짜 투명, 채팅에 붙인 webp도 투명 유지). 흰 배경으로 오면 내가 가장자리 흰색만 지우되, 사용자에게 그렇게 했다고 말한다.
- 첨부 1에 옆 칸 조각이 보이면 "그리지 않는다"로 막는다(크레스가루몬, 워그레이몬).

**결과가 다를 때 (사용자 결정)**
- 2차 수정 요청문을 쓰지 않고 1차 요청문을 그대로 다시 보낸다. 수정 요청은 GPT가 앞 결과를 거의 그대로 다시 그려 효과가 작았다(메탈시드라몬 입, 블리츠그레이몬 골반 155→86화소).
- 요청 자체를 바꿔야 하면 1차 요청문을 고쳐서 새 대화에서 보낸다.

**받은 뒤 확인 – 도구 `원본그림/_도구/02_교체/`**
1. `fit.py <이미지> <폴더> <접두어> [톤] [아래 비율]`: 01번 다리 실루엣과 가장 잘 겹치는 배율로 맞춘다. 날개·머리가 내려가면 그림 키가 줄어서 키 기준 배율이 틀리므로 다리 기준(아래 0.4~0.6)으로 맞춘다. 비율을 바꿔도 배율이 같으면 확실.
2. `diff.py <폴더> <새02> <출력>`: 차이 이미지와 위/중간/아래 바뀐 화소 수. 아래(발)가 작고 위·중간이 크면 정상. 결과 설명은 이 숫자와 이미지를 보고 한다(눈대중으로 "바뀌었다"고 하지 않기).
3. `game.py <01> <02> <출력.gif> <목표 키>`: 게임 표시 크기(`pet.pyw` big()과 같은 계산) GIF. 사용자에게는 4배 GIF + 게임 크기 GIF + 차이 이미지를 같이 보낸다.
4. `holes.py <png>`: 몸 안 투명 구멍 수. 시라몬 01·03~12는 154화소쯤 뚫려 있음(누끼 다시 필요). 날개와 몸 사이처럼 진짜 빈 공간이면 괜찮다.
5. 캔버스 밖으로 나가 잘리는지 확인(베놈묘티스몬 날개 끝 1px).
